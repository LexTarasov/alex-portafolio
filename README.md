## About

This is my personal portfolio — built from scratch with React.js to make myself more visible as a developer and honestly document where I am in my career right now.

I'm Alexandra, a full-stack developer currently building at **Nexierge**, a pre-launch startup. My background started in frontend with React and JavaScript, and over time I've pushed into backend territory — Node.js, REST APIs, authentication systems, database design, and payment integrations with Stripe.
